# reVC

Reverse-engineered GTA Vice City. See `README.md` for building and `CODING_STYLE.md` for style.

Any code that isn't reversed original code must be wrapped in a preprocessor condition (see `src/core/config.h`).

## Multiplayer

Multiplayer work is in progress. Before touching it, read `docs/multiplayer/README.md`. It has the status, decisions log, code map and links to the design spec and plan. Update its Status and Decisions log when you change something.
